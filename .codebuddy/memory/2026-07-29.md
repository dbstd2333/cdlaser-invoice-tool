## 修复：Windows 打包后 `Cannot find module 'readable-stream/passthrough'`

- 现象：Windows 上运行打包后的 app 报 `Cannot find module 'readable-stream/passthrough'`，调用链 `lazystream` → `archiver` → `exceljs`（主进程用 `externalizeDepsPlugin` 外置依赖，不打进 bundle）。
- 根因：`readable-stream` 是 `lazystream`（`exceljs`→`archiver`→`archiver-utils`→`lazystream`）的传递依赖，在 Windows 打包产物 asar 中缺失；且之前被其它依赖提升到 v3，而 `lazystream@^2` 要的是 v2 的 API。
- 修复：
  1. `package.json` 的 `dependencies` 增加 `readable-stream: "^2.3.8"`（提升为直接依赖，确保被 electron-builder 打包进 asar，且版本与 lazystream 要求一致）。已验证安装为 2.3.8。
  2. `build.files` 显式加入 `node_modules/**/*`（加 `package.json`、`!node_modules/.bin`、排除测试与 map），避免传递依赖被剪掉。
  3. 注意不要加 `lazystream` 直接依赖——其最新版仅到 1.0.1，`0.6.0` 不存在。
- 验证：本地 `node -e "require('lazystream'); require('readable-stream/passthrough')"` 通过。Windows 需重新 `pnpm install` + `pnpm build:win` 验证。

## 彻底方案：用 xlsx-populate 替换 exceljs（2026-07-29 后续）

- 用户选择「换库到现代方案」彻底解决两个报错（readable-stream 缺失 + 解析时 `iterable is not async iterable`）。
- 决策：弃用 `exceljs@4.4.0`（停止维护，且旧 `unzipper`/流管线在 Electron 43 的 Node 32 下不兼容），改用 **`xlsx-populate@1.21.0`**（纯 JS、基于 jszip、对新 Node 友好、持续维护，且支持带样式写入：列宽/加粗/填充/numFmt/冻结/自动筛选/隐藏表）。
  - SheetJS / node-xlsx 不适用：社区版 SheetJS 不支持写样式，node-xlsx 不支持样式。
- 改动文件：
  - `src/main/excel/importers/parser-utils.ts`：读取层用轻量适配器把 xlsx-populate 包成 `ReadWorkbook/ReadSheet/ReadRow/ReadCell`（维持 `readWorkbook`/`cellToText`/`cellToInt`/`findColumnIndex` 等对外签名不变，上层 parser 几乎不改）。
  - `template-generator.ts`、`replenishment-excel.ts`、`scripts/generate-template.ts`：改用 xlsx-populate 生成/导出。
  - `customer-parser.test.ts`、`template-generator.test.ts`：改用 xlsx-populate 写夹具/读校验。
  - `src/main/types/xlsx-populate.d.ts`：xlsx-populate 无自带类型，新增本地环境声明（注意放在 `src/main` 下，因 `tsconfig.main.json` 的 include 不含 `src/types`）。
  - `package.json`：移除 `exceljs` 与 `readable-stream`；**保留 `jszip`**（`src/main/excel/tax-template/*` 直接用 jszip 操作税务模板 zip）。
- 关键经验：
  - `numFmt` 必须设在**列级**（`sheet.column(n).style('numberFormat', '@')`）才会在读取时按列返回；设在 cell 级则按 cell 读。
  - `fromBlankAsync()` 自带默认 `Sheet1`，需先 `addSheet` 再 `deleteSheet('Sheet1')`，否则会删到无可见表报错。
  - 填充背景用 `cell.style('fill', 'E0E0E0')`；冻结 `sheet.freezePanes('A2')`；自动筛选 `sheet.autoFilter = 'A1:K1'`；隐藏表 `sheet.hidden(true)`。
  - 读取日期单元格返回 JS `Date`，`cellToText` 用 `toISOString().split('T')[0]` 统一成 `yyyy-mm-dd`。
- 验证：`npx tsc --noEmit -p tsconfig.main.json` 通过；`npx vitest run src/main/excel` 10 个测试全过（含文本/数值标识符精度检测）。注意 `vue-tsc` 在本机因 `ERR_PACKAGE_PATH_NOT_EXPORTED` 崩溃，属环境问题，与改动无关。
- 注：xlsx-populate 是依赖项（dependencies），会被 electron-builder 打进 asar；`build.files` 已显式含 `node_modules/**/*`。
