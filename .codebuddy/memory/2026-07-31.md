## 已知坑：dev 模式 CSP 与 React Refresh preamble 冲突
- 报错 `@vitejs/plugin-react can't detect preamble` 根因：开发模式 Vite 注入的 React Fast Refresh **内联** preamble 脚本被严格 CSP `script-src 'self'`（无 `'unsafe-inline'`）拦截。
- 修复：`src/main/bootstrap/index.ts` 的 CSP 按 `isDev` 区分——dev 放行 `'unsafe-inline' 'unsafe-eval'`，prod 保持严格 `script-src 'self'`。生产构建不含 preamble，无需内联。
- HTTP 头 CSP 会覆盖 index.html 的 `<meta>` CSP，所以只需改 `onHeadersReceived` 处。
